You can add a Google Sign-in button anywhere with the `GoogleSignInButton` component from `vue3-google-signin`.
Google renders this button following its branding guidelines.

:::tip
The component is also registered globally as `GoogleSignInButton` once the plugin is installed.
:::

:::note
If you want a custom button, see [Creating Custom Buttons](/guide/creating-custom-buttons/).
:::

## Using the Google Sign-in button

You can use the global component or import it. We import it here for better IDE support.

<Code code={example} lang="vue" title="LoginButton.vue" />

This renders the following button on your page:

<div class="demo not-content">
  <GoogleSignInButtonExample client:only="vue" />
</div>

Check the browser console for the output.

:::tip
If you see a white box around the button generated by Google, it's probably due to a color scheme conflict.
To fix it, set `color-scheme: light` on the button's container.
:::
