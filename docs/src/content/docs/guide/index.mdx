## Prerequisite

This project uses the [Google Identity Services](https://developers.google.com/identity/gsi/web) library under the hood.
It's a set of helpers that let you add Google login to Vue 3 apps.

You need to configure a project in the [Google API Console](https://console.developers.google.com/apis) and obtain a **Client ID** by following
Google's [guide](https://developers.google.com/identity/gsi/web/guides/get-google-api-clientid#get_your_google_api_client_id).

:::tip
Make sure to properly configure **Redirects** and **JavaScript Origins** in the Cloud Console.

For popups to work, you may need to add the same URL to **both** Redirects and JavaScript Origins.
:::

:::note
If you want to use the library with Nuxt, jump to the [Nuxt section](#with-nuxt).
:::

## Setup the Library

In your application entry point (`main.js` or `main.ts`), register the plugin:

```js title="main.ts"
import GoogleSignInPlugin from "vue3-google-signin";

app.use(GoogleSignInPlugin, {
  clientId: "CLIENT ID OBTAINED FROM GOOGLE API CONSOLE",
});

app.mount("#app");
```

Now the library is ready to be used.

### Setting the client ID later

If your client ID comes from your server, pass a ref and set it when it
arrives. Nothing initializes until the ref has a value, and changing it
re-initializes every composable and button.

```ts title="main.ts"
import { ref } from "vue";
import GoogleSignInPlugin from "vue3-google-signin";

const clientId = ref<string>();
app.use(GoogleSignInPlugin, { clientId });

fetch("/api/config")
  .then((response) => response.json())
  .then((config) => (clientId.value = config.googleClientId));
```

Each composable also takes a `clientId` option, and `GoogleSignInButton` a
`client-id` prop, which override the plugin's. See
[Dynamic Client ID](/guide/dynamic-client-id/) for the details.

## With Nuxt

For **Nuxt 3 and 4**, use the [nuxt-vue3-google-signin](https://github.com/wavezync/nuxt-vue3-google-signin) module.
It installs the plugin and auto-imports `GoogleSignInButton`, the composables
and the helpers.

### Add package

```sh
npx nuxi@latest module add nuxt-vue3-google-signin
```

### Initialize

Add the module and your client ID to `nuxt.config.ts`:

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
  modules: ["nuxt-vue3-google-signin"],
  googleSignIn: {
    clientId: "CLIENT ID OBTAINED FROM GOOGLE API CONSOLE",
  },
});
```

The module also takes `locale`, the plugin's option of the same name.

Import types from the module, which re-exports all of them:

```ts
import type { CredentialResponse } from "nuxt-vue3-google-signin";
```

### Set the client ID when the server starts

The client ID is part of Nuxt's public runtime config, so an environment
variable overrides it when the server starts, and one build can serve any
client ID:

```sh
NUXT_PUBLIC_GOOGLE_SIGN_IN_CLIENT_ID=your-client-id node .output/server/index.mjs
```

`process.env` in `nuxt.config.ts` is read at build time instead. With
`nuxi generate`, the client ID is fixed when you generate.

### A client ID per request

To pick the client ID per request, for example one per domain, set
`googleSignIn: { plugin: false }` and install the plugin in your own Nuxt
plugin. Auto-imports keep working. Add `vue3-google-signin` to your
dependencies to import it.

```ts title="plugins/google-sign-in.ts"
import GoogleSignInPlugin from "vue3-google-signin";

export default defineNuxtPlugin((nuxtApp) => {
  const clientId = clientIdFor(useRequestURL().hostname); // your lookup
  nuxtApp.vueApp.use(GoogleSignInPlugin, { clientId });
});
```
