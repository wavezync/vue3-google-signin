vue3-google-signin wraps
[Google Identity Services](https://developers.google.com/identity/gsi/web)
(GIS), the library behind Sign in with Google. It gives you Google's button as
a Vue component, and One Tap and the two OAuth2 flows as composables. It works
in any Vue 3 app, and in Nuxt 3 and 4 through the
[nuxt-vue3-google-signin](https://github.com/wavezync/nuxt-vue3-google-signin)
module.

## Pick what you're building

| You want to                                                                               | Use                                 | You get                                  |
| ----------------------------------------------------------------------------------------- | ----------------------------------- | ---------------------------------------- |
| [Sign users in](/guide/google-signin-button/)                                             | `GoogleSignInButton`                | An ID token that says who the user is    |
| [Sign users in without a trip to a login page](/guide/one-tap-login/)                     | `useOneTap`                         | An ID token                              |
| [Sign users in with a button in your own design](/guide/creating-custom-buttons/)         | `useTokenClient` or `useCodeClient` | An access token or a code                |
| [Read the user's Calendar, Drive, ... in the browser](/guide/google-apis/#in-the-browser) | `useTokenClient`                    | An access token that lasts about an hour |
| [Call Google APIs from your server](/guide/google-apis/#on-your-server)                   | `useCodeClient`                     | A code your server exchanges for tokens  |

Each row links to its guide. Whichever you pick, the steps below are the same.

## Create a client ID

<Steps>

1. Open [Credentials](https://console.cloud.google.com/apis/credentials) in
   the Google Cloud console, and pick or create a project. If the console asks
   you to configure the consent screen first, give it your app's name and a
   support email.

2. Click **Create credentials** > **OAuth client ID** and choose **Web
   application**.

3. Under **Authorized JavaScript origins**, add every origin your app runs on,
   with its port. For local development add both `http://localhost` and the dev
   server's origin: `http://localhost:5173` for Vite, `http://localhost:3000`
   for Nuxt.

4. Copy the client ID. It ends in `.apps.googleusercontent.com`. It isn't a
   secret: it ships to the browser.

</Steps>

:::tip
Changes to the origins can take a few minutes to apply. If a popup fails with
`redirect_uri_mismatch`, add the same origin under **Authorized redirect URIs**
too.
:::

## Install

<Tabs syncKey="framework">
  <TabItem label="Vue">

Install the package with your package manager:

```sh
npm install vue3-google-signin
```

Register the plugin in your entry point. Keep the client ID in an environment
variable so each environment can use its own:

```ts title="src/main.ts"
import { createApp } from "vue";
import GoogleSignInPlugin from "vue3-google-signin";
import App from "./App.vue";

createApp(App)
  .use(GoogleSignInPlugin, {
    clientId: import.meta.env.VITE_GOOGLE_CLIENT_ID,
  })
  .mount("#app");
```

```sh title=".env"
VITE_GOOGLE_CLIENT_ID=1234567890-abc.apps.googleusercontent.com
```

</TabItem>
  <TabItem label="Nuxt">

Add the module. `nuxi` installs it and adds it to `modules` in
`nuxt.config.ts`:

```sh
npx nuxi@latest module add nuxt-vue3-google-signin
```

Give it your client ID. The module stores it in Nuxt's runtime config, which
reads this variable from `.env` in development and from the environment when
the server starts:

```sh title=".env"
NUXT_PUBLIC_GOOGLE_SIGN_IN_CLIENT_ID=1234567890-abc.apps.googleusercontent.com
```

Or set it in `nuxt.config.ts`:

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
  modules: ["nuxt-vue3-google-signin"],
  googleSignIn: {
    clientId: "1234567890-abc.apps.googleusercontent.com",
  },
});
```

</TabItem>
</Tabs>

## Add a sign-in button

<Tabs syncKey="framework">
  <TabItem label="Vue">

```vue title="src/components/SignIn.vue"
<script setup lang="ts">
import {
  GoogleSignInButton,
  type CredentialSuccessResponse,
} from "vue3-google-signin";

const onSuccess = ({ credential }: CredentialSuccessResponse) => {
  // An ID token (JWT). Send it to your server and verify it there.
  console.log(credential);
};
</script>

<template>
  <GoogleSignInButton @success="onSuccess" />
</template>
```

The plugin also registers `GoogleSignInButton` globally, so the import is only
there for your editor.

</TabItem>
  <TabItem label="Nuxt">

```vue title="pages/login.vue"
<script setup lang="ts">
import type { CredentialSuccessResponse } from "nuxt-vue3-google-signin";

const onSuccess = ({ credential }: CredentialSuccessResponse) => {
  // An ID token (JWT). Send it to your server and verify it there.
  console.log(credential);
};
</script>

<template>
  <GoogleSignInButton @success="onSuccess" />
</template>
```

`GoogleSignInButton`, the composables and the helpers are auto-imported. Import
types from `nuxt-vue3-google-signin`.

</TabItem>
</Tabs>

Start your dev server and open the page. Google draws its button; sign in and
the ID token shows up in the console.
