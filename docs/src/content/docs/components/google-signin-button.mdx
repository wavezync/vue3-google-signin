`GoogleSignInButton` renders Google's own Sign in with Google button. The plugin
registers it globally, and you can also import it from `vue3-google-signin`.

```vue
<GoogleSignInButton theme="filled_black" shape="pill" @success="onSuccess" />
```

## Playground

Change the props and the button re-renders. It's the real button, so you can
sign in with it too.
